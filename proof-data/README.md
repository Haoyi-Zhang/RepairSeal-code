# Frozen proof-DAG study data

`structured-study.json` is the aggregate frozen-core scientific record. It is regenerated by `tests/structured_study.py` and compared during `tests/reproduce_all.py` after removing only documented environment-dependent time, peak-RSS, and generation-timestamp fields.

Deterministic request and evidence directories:

- `fixture-inputs/`: 80 receiver-authoritative fixture requests.
- `fixture-certificates/`: 80 full-vector fixture certificates.
- `stress-inputs/`: 300 generated stress requests.
- `stress-certificates/`: 300 full-vector stress certificates.
- `controls/`: representative full-vector corruptions.
- `refutation-witnesses/`: 285 compact one-point refutation certificates.
- `refutation-controls/`: representative compact-certificate corruptions.
- `holdout-differential/inputs/`: 400 grammar-generated authoritative requests plus per-case results and seeds.

Authoritative input order is carried by the insertion order of each request's `inputs` map. Request files are serialized without key sorting. In particular, all 300 four-parameter stress requests and all 142 four-parameter grammar requests retain `x,y,z,t`; certificate `input_order` is checked against the request and is never used to choose request semantics.

`disk-replay-audit.json` records the retained-file gate. The gate strict-loads 780 request files from disk, independently recovers their expected ordered requests from the fixture/stress generators and retained grammar seeds, validates 380 full-vector certificates and 285 compact core certificates, and rechecks 400 grammar results. This is distinct from regenerating requests in memory and comparing bytes.

Complete control records are in `tamper-controls.json` (6,000 full-vector mutations), `refutation-controls.json` (2,850 compact mutations), and `acceptance-misuse-controls.json` (95 forged refutations of accepted requests). Aggregate JSON stores deterministic indexes over complete result/control records so a clean reproduction checks the full populations, not only saved representatives.

The decisive work accounting is explicit:

- on 20 correct fixtures, full-vector checking and certificate-free topological evaluation each perform 45,198 node--point cells;
- across all 380 frozen-core requests, `proof_operation_counts_all.proof_cells` is 1,179,684;
- the certificate-rebuild diagnostic still receives the full certificate and records 45,198 outer proof cells plus 309,582 internal recursive visits on correct fixtures;
- the separately timed certificate-free `Session/direct_result` path is a different algorithm and has no 309,582-cell interpretation.

For the same 285 refuted requests, median full-vector and compact encodings are 15,604 and 667 bytes. The ratio of those medians is 23.3943; the median of paired per-request ratios is 23.2294. The all-380 full-vector median (15,213 bytes) is retained separately and is not a valid denominator for a refutation-only comparison.

The 400 grammar cases use 9, 27, or 81 points (125, 133, and 142 cases) and 15--163 nodes with median 69.5. `edge-case-regression.json` retains producer topological-reuse, actual AST-depth/literal limits, and conservative selector-admission checks.

Timing files are descriptive and expected to change across hosts. All scientific count, status, request-order, certificate, and grammar-result gates are deterministic.
